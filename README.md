> _**Masih dalam pengerjaan dan belum lengkap fiturnya. Usulan fitur tetap diterima.**_

Alat pengelola berkas untuk Android yang fokus pada perawatan rutin. Tujuan utamanya cuma satu: mengosongkan ruang dan membuang data yang tidak terpakai.

Isinya antara lain:

* Menghapus sisa data aplikasi yang sudah di-uninstall
* Membuang berkas sekali pakai seperti cache
* Filter yang bisa diatur sendiri untuk berkas acak
* Penjadwalan tindakan otomatis
* Menonaktifkan atau mengatur aplikasi lain
* Ringkasan pemakaian penyimpanan
* Pencarian data duplikat
* Dukungan akses root dan lapisan bantuan khusus

Proyek ini adalah penerus dari alat serupa generasi sebelumnya. Kodenya ditulis ulang dari nol, disesuaikan dengan versi Android terbaru, dan hanya membawa fitur yang paling banyak dipakai dari pendahulunya. Perbandingan lengkap keduanya ada di halaman tanya-jawab.

## Unduhan

Berkas pemasangan tersedia di toko aplikasi resmi, jalur uji beta, halaman rilis repositori, dan repositori aplikasi bebas.

## Mendukung proyek

Tidak ada iklan di dalamnya, dan data pengguna tidak dijual.

Pengembangan dibiayai oleh kontribusi pengguna secara langsung — entah lewat pembelian versi upgrade atau lewat dukungan rutin ❤️.
